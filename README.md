
# Linux Security Audit

一个基于 Python 开发的 Linux 服务器基础安全检查工具。

## 一、项目介绍

本项目旨在通过 Python 脚本，对 Linux 服务器进行基础安全配置检查，帮助初学者了解 Linux 系统安全。

## 二、项目目标

- 检查 Linux 系统基本信息
- 检查用户与权限配置
- 检查 SSH 远程登录配置
- 检查系统防火墙状态
- 检查系统更新情况
- 生成基础安全检查报告

## 三、技术栈

- Python
- Linux
- GitHub

## 五、学习目标

通过本项目学习：

1. Linux 基础命令
2. Python 基础编程
